Password Manager Android App

This project is a modern password manager designed to securely store and manage user credentials on Android devices. 
Built with Jetpack Compose for a smooth and intuitive UI, the app utilizes AES-256 encryption to ensure maximum data protection.

Key Features:

- **Secure Storage:** All passwords and sensitive data are encrypted using AES-256 before being saved locally.
- **Biometric Authentication:** Strong (Class 3) Biometric protection for app access and autofill operations.
- **Native Autofill Service:** Seamless integration with Android OS to auto-fill and auto-save passwords across apps and browsers.
- **Smart Categorization:** Automatically separates App credentials from Web credentials based on package names.
- **Password Management:** Supports generating strong passwords, updating existing credentials, soft-deleting (recycle bin), and permanent deletion.
- **Modern UI:** Jetpack Compose ensures a responsive, seamless user experience with iOS-inspired aesthetics.
- **Lightweight & Offline:** All data is stored locally on-device without any external API calls.

This project utilizes best practices in Android development with a focus on security, persistence, and modern UI paradigms through the use of Jetpack Compose and the secure encryption method of AES-256 GCM.
